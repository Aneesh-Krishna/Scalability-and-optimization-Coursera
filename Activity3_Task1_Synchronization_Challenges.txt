TASK 1: IDENTIFY THE SYNCHRONIZATION CHALLENGES - HIGH-TRAFFIC NEWS PLATFORM
===========================================================================

Scenario: A news website runs on many servers in several regions and uses a
distributed cache for headlines, article summaries, trending topics, and user
comments. Because each server and region can hold its own cached copy, the
copies can fall out of sync with the database and with each other.

SUMMARY OF ROOT CAUSES
----------------------

- Caches are refreshed on a timer instead of when the data actually changes.
- Updates are not broadcast to every server and region at the same time.
- Network latency and replication lag between regions delay updates.
- Updates carry no version number, so old data can overwrite new data.
- Multiple cache layers (app cache and CDN) are not cleared together.
